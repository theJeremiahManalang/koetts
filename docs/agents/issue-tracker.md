# GitHub Issues

Use `gh` for repository issues. Resolve the repository from `git remote -v`; inspect issue body, comments, labels, and linked dependencies before acting. Issue and pull request numbers share one namespace.

Complete prompt approval before claiming substantial new work. External issue creation, comments, and state changes require user authorization. Use `--body-file` for multiline text. Inspect actual repository labels before assigning one; do not assume template label conventions exist.
