# Event-driven hosted operation dispatch

Hosted queue changes create durable Firestore dispatch signals in the same transaction as the operation transition; Eventarc delivers those signals to the private API, which claims work from authoritative operation state. Studio receives status through authenticated SSE backed by Firestore change listeners, keeping browser data access behind the API. Scheduled coordination remains for crash reconciliation and missed-signal repair, not normal dispatch. Signals are duplicate, unordered wake-ups, so fences, capacity transactions, and budget admission remain authoritative.
