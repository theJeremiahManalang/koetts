# Implementation plans

Plans define intended scope and acceptance. Use [current status](../STATUS.md)
to identify completed offline work and remaining live gates.

- [Hosted service plan](hosted-service-plan.md): current hosted phases, operating
  constraints and separately authorized live validation.
- [Architecture alignment plan](architecture-alignment-plan.md): original S0–S5
  scope definitions; these are distinct from the hosted phase numbers.
- [Scope assignment prompt](architecture-alignment-prompt.md): entrypoint for an
  explicitly selected original alignment scope.
